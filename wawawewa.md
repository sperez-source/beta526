# Hello World Code

This file contains classic Hello World examples in various programming languages.

## Python

```python
print("Hello, World!")
```

## JavaScript

```javascript
console.log("Hello, World!");
```

## Java

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## C

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

## C++

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

## Go

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

## Rust

```rust
fn main() {
    println!("Hello, World!");
}
```

## Bash

```bash
echo "Hello, World!"
```
